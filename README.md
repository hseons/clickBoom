# clickBoom

一个轻量、原生的 macOS 全局鼠标点击特效工具。它会监听鼠标点击，并在点击位置绘制即时动画，让演示、录屏、直播和日常操作更有反馈感。

项目使用 SwiftUI 和 macOS 原生 API 编写，不依赖第三方运行库。

## ✨ 功能特性

- 全局监听鼠标点击与滑动（左键、右键与中键，右键/中键可单独关闭）
- 11 种可切换的点击效果：
  - 火花：短线条向外散开
  - 圆环：一段圆弧从点击位置展开
  - 光线：几条细光线快速划过
  - 彩纸：小块彩纸轻轻飘开
  - 表情：点击弹出自定义 Emoji，带轻微弹性、漂浮和旋转动画
  - 水波：三圈涟漪依次向外扩散、逐圈变淡
  - 星芒：四长四短的尖细星芒 + 中心高光，像镜头光晕
  - 像素：8-bit 小方块四散旋转、边飞边缩小
  - 爱心：小爱心错峰上浮，带轻微摇摆与旋转
  - 烟花：焰火炸开后拖尾下坠，中心带一圈闪光
  - 闪电：锯齿电弧向外劈开，外层发光、内层亮芯
- 独立的「滑动拖尾」开关：移动或拖动鼠标时留下渐隐光带，可与任意点击效果同时开启；内置光带、毛笔、霓虹、彗星、丝带、星尘 6 种拖尾样式，单击时补一个光点；拖尾有独立颜色、粗细、透明度和停留时长，默认跟随点击颜色
- 支持自定义效果颜色，并提供 6 个常用色块一键切换
- 支持输入一个或多个自定义 Emoji，多个 Emoji 会在每次点击时随机选择；也可点选常用 Emoji 快速加入
- 内置 6 组快捷预设：默认、蓝光、圆环、彩纸、赛博、烟花
- 支持把自己的整套参数保存成自定义预设（同名覆盖），随时一键套用或删除；支持名称搜索、重命名、复制、收藏筛选、拖拽排序及右键上移 / 下移
- 菜单栏「收藏与最近」最多展示 8 项，优先收藏并按最近使用补齐；完整列表在控制面板管理
- 支持把自定义预设导出为版本化 JSON 文件，并重新导入或跨设备合并；导入前显示合并摘要，同名预设会自动保留副本；自动保存导入前副本，重启后仍可撤销上次导入（导入后编辑预设会停用撤销）
- 支持暂停 15 / 30 / 60 分钟：演示中途临时关掉效果，到点自动恢复
- 支持自定义全局快捷键（默认 ⌃⌥B）：点一下直接按新的组合键，需包含 ⌃ / ⌥ / ⌘，可在任意 App 里快速开关特效；录制时会先探测组合是否被占用，冲突时保留原快捷键
- 支持「应用规则」：按 App 单独决定静默、进入时自动套用某个自定义预设、只关拖尾但保留点击特效、以及这个 App 里显不显示键盘 HUD；没配规则的 App 沿用全局设置，原来的排除列表会自动迁移成「静默」规则
- 支持「键盘与快捷键」HUD：在指针所在屏幕底部显示刚按下的键，⌃⌥⇧⌘ 组合紧凑成一行、最多 3 个键帽，1.6 秒后淡出；可选只显示带修饰键的快捷键、三档尺寸和 1–3 行保留行数。密码输入框（安全键盘输入）期间自动隐藏，不进缓存、不落盘
- 支持「演示模式」：一键或按 ⌃⌥P 临时跳过「全屏静默」和「免打扰时段」，同时打开键盘 HUD 与聚光环；退出时逐项还原进入前的设置，应用规则里的静默仍然生效。菜单栏、状态行和控制面板都能切换
- 支持「点击音效」：清脆 / 柔和 / 木质三种音色，波形在运行时合成不占包体；音量走对数曲线，30ms 内连点只响一次，静默、暂停和排除状态下不发声。走系统输出，系统录屏和 QuickTime 默认不收录
- 支持「全屏时自动静默」：前台 App 全屏时自动暂停特效和拖尾，退出全屏立即恢复，看电影、演示时不用手动关
- 支持「免打扰时段」：设定起止时间（如 22:00 – 次日 08:00）和生效的星期（每天 / 工作日 / 周末 / 逐日），到点自动暂停点击特效、拖尾和聚光环，结束时间自动恢复；跨零点按开始那天判断，时段内还能「本次跳过」放行到下一个边界，开会、夜间录屏不用每天手动关
- 菜单栏与控制面板统一显示运行状态，直接解释权限、定时暂停、免打扰时段、应用排除或全屏静默原因，并提供授权、恢复与静默设置入口
- 静默时清理聚光环、粒子和旧拖尾，退出后从实时指针位置恢复；全屏判断随应用、空间和屏幕变化更新，免打扰到点切换由一次性计时器触发，不做轮询
- 状态行的信息按钮和「系统 → 查看运行诊断」可按需查看权限、作用应用、屏幕数、移动监听、粒子和轨迹点数；手动刷新，不保存或上传
- 支持「设置备份」：把两个全局快捷键、应用规则、键盘 HUD、点击音效、免打扰时段和全屏静默开关导出成 JSON（schema v2），换机或重装后一键导入；1.5–1.11 的旧备份照常导入，排除列表会转成静默规则
- 支持调整粒子数量、大小、扩散半径、动画时长和缩放比例
- 新增鼠标聚光环：录屏和演示时持续标出指针位置，支持自定义颜色、大小、透明度和点击脉冲
- 支持区分左键、右键和中键，右键与中键可使用独立颜色
- 拖尾支持始终跟随、仅拖动、按住 Option 或按住 Command 四种触发方式
- 内置教程、录屏、直播、极简四类演示场景，一键切换整套效果
- Emoji 模式支持在控制面板或菜单栏直接编辑自定义表情
- 菜单栏提供快速面板，可直接开关、预览、定时暂停、套用预设，并快速调整常用参数；图标会随开关变暗，暂停时显示暂停标记
- 面板内可一键「预览」当前效果，调完参数立刻看到结果，也能一键「恢复默认设置」
- 跟随系统「减弱动态效果」：开启后自动收起旋转与摇摆
- 随机样式：每次点击自动抽取一种样式
- 连续点击放大：短时间连续点击会逐步增加粒子数量和范围
- 支持开机自启（基于系统登录项，可随时在控制面板或菜单栏开关）
- 点击、拖尾、聚光环、点击音效都不需要任何系统权限；只有「键盘与快捷键」HUD 需要「输入监控」，面板里给出一键授权、回来自动复查、以及授权后重启 App 的入口
- 支持多显示器：覆盖层铺满所有屏幕，副屏/竖屏点击同样有效，插拔显示器自动适配
- 启动时只留在菜单栏，不弹面板（开机自启也不会打断登录），点 Dock 图标可随时叫回
- 空闲时暂停动画渲染，不点击就不占绘图资源
- 控制面板可拖拽调整窗口大小
- 内置「检查更新」，直接对比 GitHub 上最新 Release；启动后每天自动检查一次，有新版本时菜单栏图标显示小圆点
- 设置会自动保存，下次启动时继续使用
- 使用透明悬浮层绘制，不影响鼠标正常操作
- 原生 SwiftUI 界面，轻量且易于扩展

## 🖥️ 系统要求

- macOS 26.0 或更高版本
- Xcode 26.0 或更高版本（仅编译时需要）

点击、拖尾、聚光环和点击音效不需要任何权限，装好就能用。「输入监控」只在开启键盘 HUD 时才需要：系统设置 → 隐私与安全性 → 输入监控 → 勾选 ClickBoom。macOS 对这项授权只对新启动的进程生效，勾选后从面板点「重启 App」即可；从系统设置切回来时面板会自动复查状态。

从 1.12.2 起安装包用固定证书签名，授权可以跨版本保留；更早的 ad-hoc 版本每更新一次都会被系统当成新 App，需要在输入监控列表里把旧的 ClickBoom 条目删掉再重新勾选一次。

## 📦 安装

1. 到 [Releases](https://github.com/hseons/clickBoom/releases) 下载最新的 `ClickBoom-x.y.z.dmg`。
2. 打开 DMG，把 ClickBoom 拖进「应用程序」。
3. 首次打开时，如果看到「无法验证开发者」的提示，说明安装包还没有经过 Apple 公证。任选一种方式放行：
   - 在「应用程序」里 **右键点击 ClickBoom → 打开 → 再点「打开」**；
   - 打开 系统设置 → 隐私与安全性，在底部点「仍要打开」；
   - 或者用命令行去掉隔离标记：
     ```bash
     xattr -dr com.apple.quarantine /Applications/ClickBoom.app
     ```
4. 随便点几下鼠标就能看到效果；键盘 HUD 需要额外授予「输入监控」，在控制面板对应卡片里按提示开启。

> 面板默认不再随启动弹出（开机自启时也不会打断登录），从菜单栏图标或 Dock 图标进入即可。

## 🚀 快速开始

### 使用 Xcode

1. 克隆仓库并进入项目目录：

   ```bash
   git clone https://github.com/hseons/clickBoom.git
   cd clickBoom
   ```

2. 使用 Xcode 打开 `clickBoom.xcodeproj`。
3. 选择 `clickBoom` scheme，点击运行。
4. 点击 macOS 菜单栏中的 ClickBoom 图标，可快速开关效果、切换样式并调整常用参数；也可以打开完整控制面板。
5. 在任意应用中点击鼠标，查看点击特效。

### 新颖玩法

- 点击“快捷预设”可以快速切换一整套颜色、粒子和动画参数。
- 调出满意的效果后，在「预设 → 我的预设」点「保存当前」，给它起个名字；右键可收藏、重命名、复制、上移 / 下移或删除，拖到另一项前即可排序。名称搜索和星标筛选方便查找；排序前需清除筛选。菜单栏「收藏与最近」可快速套用常用预设。
- 在「导入 / 导出」选择 JSON 后，先核对新增、更新和改名数量再确认导入；如需回退，在同一菜单选「撤销上次导入」。导入后编辑或使用预设会停用撤销，防止丢失后续变化。
- 按 `⌃⌥B` 可以在任意 App 里开关特效，不用切回菜单栏。
- 演示或录屏中途想临时关掉效果，用菜单里的「暂停 15 / 30 / 60 分钟」；到点自动恢复，也可以随时点「立即恢复」。
- 开启“随机样式”后，每次点击都会从现有 11 种效果中随机选择一种。
- 开启“连续点击放大”后，在 1 秒内连续点击会逐步增加粒子数量、尺寸和扩散范围；停止点击后会自动归零。
- 打开“滑动拖尾”开关后，鼠标不用按住也会跟随滑动留下光带，点击时的效果照常播放；拖动窗口、圈选文件或在白板上写字时尤其明显。开关下方可以在光带、毛笔、霓虹、彗星、丝带、星尘 6 种笔触之间切换，还能单独调颜色、粗细、透明度和停留时长（默认跟随点击颜色）；快速滑动时轨迹会自动平滑，右键/中键拖动同样受右键开关控制。
- 选择“Emoji 表情”后，在控制面板或菜单栏输入 `✨🔥💖` 这类 Emoji 串；每次点击只弹出一个表情，动画更轻巧。下面的快捷 Emoji 点一下就能加入或移除。

### 运行状态与诊断

面板状态按「关闭 → 定时暂停 → 免打扰时段 → 应用排除 → 全屏静默 → 演示模式 → 运行中」的顺序显示首个生效原因；输入监控只影响键盘 HUD，不影响鼠标特效。打开面板时仍保留最近外部应用的上下文；「预览」可在关闭或静默期间单独使用。

点击状态行右侧的信息按钮，或在控制面板「系统」中点击「查看运行诊断」。诊断在打开和手动点击「刷新」时读取，数值带读取时间，不连续采样、不写文件、不上传。诊断里的「性能档位」「帧绘制耗时」和「预算上限」反映当前绘制预算：默认是完整画质（600 粒子 / 180 轨迹点 / 60 fps），只有实测绘制耗时持续超出预算才逐档收紧到平衡或节能，压力消失后再逐档恢复；颜色、笔触和拖尾形状不受影响。全屏自动静默本身使用低频复查，以便指针静止时也能检测退出全屏；关闭该选项、总开关关闭、暂停、处于演示模式、免打扰时段或应用被排除时停止复查。免打扰时段只在起止时刻切换一次，用一次性到点触发的计时器代替轮询。

### 命令行构建

```bash
xcodebuild \
  -project clickBoom.xcodeproj \
  -scheme clickBoom \
  -configuration Debug \
  -sdk macosx \
  build
```

核心逻辑测试使用 XCTest，直接编译真实 App 模块：

```bash
swift test
```

如果 `xcode-select -p` 指向 CommandLineTools，需要先 `sudo xcode-select -s /Applications/Xcode.app/Contents/Developer`，或者临时指定：

```bash
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild ...
```

另外，仓库如果放在 iCloud Drive、网盘同步目录等 File Provider 路径下，产物会被写入 FinderInfo 等扩展属性，签名时会报
`resource fork, Finder information, or similar detritus not allowed`。把构建目录指到系统临时目录即可：

```bash
xcodebuild ... -derivedDataPath "${TMPDIR}/clickboom-build"
```

### 打安装包

```bash
./scripts/release.sh          # 输出 dist/ClickBoom-<版本>.dmg（arm64 + x86_64 通用二进制）

PUBLISH=1 ./scripts/release.sh   # 构建完成后直接传到 GitHub Release（需 gh 已登录）
```

推 `v*` 标签时，GitHub Actions 也会自动构建一次并把 DMG 补到 Release；如果 Release 里已经有 DMG 附件，CI 不会覆盖（保留本地签名版本）。Release 说明由 `scripts/changelog-notes.sh` 从 `CHANGELOG.md` 提取当前版本段落。

需要正式分发（不再被 Gatekeeper 拦截）时，用 Developer ID 证书签名并公证：

```bash
xcrun notarytool store-credentials clickboom \
  --apple-id <你的 Apple ID> --team-id <TEAMID> --password <App 专用密码>

SIGN_IDENTITY="Developer ID Application: Your Name (TEAMID)" \
NOTARY_PROFILE=clickboom \
./scripts/release.sh
```

## 🎛️ 参数说明

| 参数 | 说明 |
| --- | --- |
| 效果颜色 | 设置当前点击动画的颜色 |
| 数量 | 每次点击生成的粒子数量 |
| 大小 | 火花、光束或彩纸的基础尺寸 |
| 半径 | 动画向外扩散的范围 |
| 持续时间 | 单次点击动画的显示时长 |
| 缩放 | 整体效果的放大或缩小比例 |
| 随机样式 | 每次点击随机选择一种效果样式 |
| 滑动拖尾 | 独立开关；开启后移动鼠标留下渐隐光带，可与点击效果同时使用 |
| 拖尾样式 | 光带 / 毛笔 / 霓虹 / 彗星 / 丝带 / 星尘，6 种不同笔触的拖尾；毛笔的粗细随滑动速度变化 |
| 跟随点击颜色 | 打开时拖尾使用点击效果的颜色；关闭后单独选色 |
| 拖尾颜色 | 拖尾自己的颜色，仅在关闭「跟随点击颜色」后生效 |
| 拖尾粗细 | 光带和笔触的基准宽度 |
| 拖尾透明度 | 拖尾整体的透明度，不影响点击效果 |
| 拖尾停留 | 拖尾在屏幕上停留的时长，与点击动画时长分开设置 |
| 连续点击放大 | 连续点击时逐步增加效果范围 |
| 自定义 Emoji | 输入一个或多个 Emoji，点击时随机弹出一个 |
| 全局快捷键 | `⌃⌥B`，在任意 App 中开关特效；可自行录制，冲突会提示 |
| 全屏静默 | 前台 App 全屏时自动暂停特效，默认开启 |
| 免打扰时段 | 每天的起止时间（默认 22:00 – 08:00，跨零点按一段处理）；默认关闭 |
| 定时暂停 | 暂停 15 / 30 / 60 分钟后自动恢复 |
| 我的预设 | 保存当前整套参数，同名覆盖，可一键套用或删除 |

```text
├── SettingsBackupLogic.swift # 设置备份的编码、校验与合并
├── QuietHours.swift        # 免打扰时段的区间判断与下一次切换时刻
├── QuietHoursView.swift    # 控制面板与状态弹窗共用的免打扰控件
├── FrontmostAppTracker.swift # 记录最近的非自身前台 App
└── Assets.xcassets/        # 应用图标和颜色资源
clickBoom.xcodeproj/        # Xcode 工程文件
Tests/ClickBoomTests/       # 核心逻辑单元测试
Package.swift               # SwiftPM 测试入口
scripts/release.sh          # 打包 DMG（通用二进制，可选签名/公证）
```

界面和渲染主体仍集中在 `ContentView.swift`；监听生命周期由 `RuntimeController.swift` 管理，可独立验证的规则已拆到逻辑文件：

- `AppState`：保存开关和特效参数
- `EffectStyle`：管理可用的效果样式
- `EffectEngine`：创建和清理点击粒子，维护滑动拖尾轨迹
- `EffectOverlayView`：通过 `Canvas` 和 `TimelineView` 绘制动画
- `PerformanceBudget`：绘制耗时采样、档位预算与自适应决策
- `PresetArchiveCodec`：预设归档校验、参数规范化和合并
- `AppVersionComparator`：语义化版本的逐段比较
- `InputMapping`：鼠标按钮权限与拖尾触发规则
- `HotKeySpec`：全局快捷键的合法组合、展示文案和存储格式
- `AppExclusionLogic`：应用排除列表的规范化、去重与增删
- `FullScreenLogic` / `FullScreenDetector`：窗口是否铺满屏幕的几何判定与按进程、屏幕配置缓存的查询
- `RuntimeStatus` / `RuntimeController`：统一生效规则，管理应用 / 空间 / 屏幕变化、静默清理、恢复及监听生命周期
- `QuietHours`：免打扰时段的跨零点判断、边界时刻计算与文案格式化
- `RuntimeStatusView` / `RuntimeDiagnosticsView`：两个面板共用状态提示，按需读取运行诊断
- `SettingsBackupLogic`：设置备份的编解码、schema 校验与排除列表合并
- `FrontmostAppTracker`：菜单栏面板打开前记住最近的前台 App

## 🗒️ 更新日志

本轮实现范围、后续启动条件和验收范围见 [ROADMAP.md](ROADMAP.md)；1.12 的完整方案与交付回顾见 [docs/next-release-1.12.md](docs/next-release-1.12.md)，下一版（1.13 屏幕标注与预设分享）见 [docs/next-release-1.13.md](docs/next-release-1.13.md)。

### 1.12.2

- 修复键盘 HUD 打开后按键没反应：没授权时会误判为「监听成功」，现在如实提示
- HUD 卡片新增「监听中 / 兼容模式 / 未授权 / 待重启」状态行与「预览浮层」按钮
- 发版改用稳定签名证书，系统授权不再随每次更新失效

### 1.12.1

- 修复升级到 1.12.0 后点击、拖尾、聚光环全都不显示：鼠标特效不再依赖「输入监控」权限，权限只影响键盘 HUD。
- 修复「系统设置里勾上了，面板还说未授权」：区分「未授权」与「已授权但需要重启」，HUD 卡片给一键重启，从系统设置切回来会自动复查。
- 键盘 HUD 只在开关打开且已授权时才安装事件监听，不会再无授权时反复触发系统询问。

### 1.12.0

- 新增「键盘与快捷键」HUD：CGEventTap 只读监听按键，装上权限后立即生效，被系统停掉会在 3 次内自动重建、再失败切到 NSEvent 全局监听；开启安全键盘输入（密码框）时立刻清空并暂停显示。
- 键帽按 ⌃⌥⇧⌘ + 主键排列，一行最多 3 个、1.6 秒淡出，可选只显示快捷键组合、小 / 中 / 大三档尺寸、保留 1–3 行；HUD 跟随指针所在屏幕，不受全屏静默和免打扰影响，仍受应用规则控制。
- 新增「演示模式」：一键或按 ⌃⌥P 临时关掉全屏静默和免打扰时段，并打开键盘 HUD 与聚光环；退出时逐项还原进入前的设置，应用规则里的静默照常生效。状态行新增「演示模式运行中」。
- 全局快捷键改为按槽位管理：「开关特效」（默认 ⌃⌥B）和「演示模式」（默认 ⌃⌥P）各自注册、各自录制与冲突探测，互不影响。
- 「应用排除」升级为「应用规则」：每个 App 可单独设置静默、进入时套用某个自定义预设、只关拖尾保留点击、以及是否显示键盘 HUD；规则只存预设 id，预设改了规则自动跟随。旧排除列表自动迁移成静默规则。
- 新增点击音效：清脆 / 柔和 / 木质三种运行时合成波形，对数音量曲线（默认 35%），30ms 防抖，静默 / 暂停 / 排除时不发声；不需要新权限。
- 设置备份升到 schema v2，包含应用规则、演示快捷键、键盘 HUD 和音效设置；导入 v1 备份时把排除列表转成静默规则，已有规则优先。
- 新增 38 个测试（总计 146 个）：演示模式的进入 / 退出还原与不落盘、状态优先级、快捷键槽位、应用规则的规范化 / 合并 / 迁移、备份 v1→v2、音量曲线与防抖、按键标签与安全输入判定。
- 通用 DMG 支持 Apple Silicon 和 Intel，使用 ad-hoc 签名，未经过 Apple 公证。

### 1.11.0

- 免打扰时段支持按星期选择（每天 / 工作日 / 周末 / 逐日），跨零点按开始那天判断；时段内可「本次跳过」，到下一个边界自动恢复。
- 「本次跳过」在菜单栏状态弹窗和控制面板都能用；改起止时间、改星期、导入备份或恢复默认会作废旧跳过。
- 设置备份加入可选星期字段，schema 升到 v2；运行诊断新增免打扰的星期与跳过状态、全屏复查间隔。
- 全屏复查在指针静止 30 秒后从 0.5 秒退避到 2.0 秒，指针一动立即恢复；实测静止 CPU 0.185% → 0.055%，package 唤醒 83 → 22 次/分。
- 补齐 1.9.0 的 12 场景实机基线，移动场景 8.7–15.5% 列为下一版目标；测试总数为 108 个。
